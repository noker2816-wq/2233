# 서무마을

노션 "서무 할 일"(할 일 메모 DB)을 대구 중구 3D 마을로 보여주는 페이지. 동물 주민들이 돌아다니고, 중구청 광장의 대형 전광판 한 면에 업무 현황이 다 나온다.

- **광장 대형 전광판** (한 면에 전부): 남은 일·오늘 기한·날짜 지남·7일 이내·날짜 미정·7일 해낸 일 숫자, 기한 현황 전체 목록(넘치면 10초마다 페이지), 오늘 할 일, 날짜 지남·처리 확인, 업무유형별 막대, 날짜 미정, 최근 해낸 일, 실시간 시계, 하단 자막. 앞뒤 양면
- **중구청**: 광장 동쪽 공평로변 대형 청사. 누르면 전체 남은 업무 목록
- **업무유형 상점 7곳** (광장 양옆): 수합 우체국, 회계 은행, 인사 관청, 정보공개 도서관, 감사 사무소, 행사 공연장, 공람 게시판. 지붕 위 숫자 = 그 유형 남은 일 (빨강 날짜 지남 / 주황 오늘 / 파랑 그 외)
- **12개 동 행정복지센터**: 동인동·삼덕동·성내1~3동·대신동·남산1~4동·대봉1·2동을 중구청 기준 실제 지도상 대략적인 위치에 배치 (도로와 겹치지 않게 몇 곳은 조금 옮김). 누르면 제목·미제출에 그 동 이름이 들어간 업무
- **지도 요소**: 신천, 공평로·중앙대로·달구벌대로·국채보상로, 반월당, 동성로, 서문시장, 달성공원, 경상감영공원
- **주민 16종**: 고양이·강아지·곰·토끼·여우·판다·돼지·펭귄·코알라·호랑이·병아리·쥐·너구리·사슴·양·개구리. 안경·공무원증·넥타이·모자·리본·가방·치마 등 랜덤. 광장·동네 앞마당·큰길 인도를 다니며 임박 업무를 말풍선으로 말함
- **자동 둘러보기**: 마을 전체 → 전광판 → 광장 → 중구청 순서로 계속 돌아감 (사무실 TV용). 직접 움직이면 1분 멈춤
- 한국시간 기준 낮·노을·밤 (밤에는 건물 창문·가로등 켜짐). 이름표는 멀리서 볼 때만 표시
- 단축키: `F` 전체 화면, `B` 전광판 보기, `L` 저장된 비밀번호 지우고 잠그기

주소 옵션: `?demo=1` 예시 데이터, `?lite=1` 그림자 끄기(저사양 PC), `?sky=day|dusk|night` 하늘 고정, `?view=board|plaza|hall|overview` 시점 고정
평면 LED 전광판만 보려면 `board.html`

## 구조

```
노션 ──(GitHub Actions, 평일 10분마다)── scripts/sync.mjs
          │  업무 제목·날짜·상태만 추림 (메모 본문은 안 씀)
          │  BOARD_PASSWORD로 AES-256-GCM 암호화
          ▼
   site/data.enc.json ── GitHub Pages ── 브라우저에서 비밀번호로 복호화
```

레포가 공개라서 코드와 페이지 주소는 누구나 볼 수 있지만, 업무 데이터는 암호화된 파일로만 배포된다. git 기록에도 데이터가 남지 않는다(배포 아티팩트로만 올라감).

## 처음 설정 (한 번만)

1. **노션 통합 만들기**
   [노션 통합 관리](https://www.notion.so/profile/integrations) → 새 통합 → 유형 "내부", 이름 `서무 전광판` → 기능은 **콘텐츠 읽기만** 체크 → 저장 후 **내부 통합 시크릿**(`ntn_...`) 복사

2. **노션 DB에 통합 연결**
   노션 "서무 할 일" 페이지 오른쪽 위 `•••` → 연결(Connections) → `서무 전광판` 추가

3. **GitHub 시크릿 등록**
   레포 Settings → Secrets and variables → Actions → New repository secret
   - `NOTION_TOKEN` : 1번에서 복사한 시크릿
   - `BOARD_PASSWORD` : 전광판 비밀번호 (12자 이상 권장, 암호화 파일은 누구나 받을 수 있어서 짧으면 뚫릴 수 있음)

4. **GitHub Pages 켜기**
   Settings → Pages → Build and deployment → Source: **GitHub Actions**

5. **첫 실행**
   Actions 탭 → "전광판 동기화·배포" → Run workflow
   끝나면 `https://<아이디>.github.io/<레포명>/` 에서 비밀번호 입력 (마을과 평면 전광판 비밀번호 같음)

## 참고

- GitHub 예약 실행은 몇 분씩 늦어질 수 있다. 화면 오른쪽 위에 마지막 동기화 시각이 나오고, 40분 넘게 안 바뀌면 "동기화 지연"으로 표시된다.
- 공개 레포는 60일 동안 커밋이 없으면 GitHub가 예약 실행을 자동으로 멈춘다. 그때는 Actions 탭에서 다시 켜면 된다.
- 비밀번호를 바꾸면 다음 동기화부터 새 비밀번호로 열린다. 기존 화면은 자동으로 잠금 화면으로 바뀐다.
- 날짜가 지난 업무는 "확인" 대상으로만 표시하고 미처리로 단정하지 않는다. 완료 여부는 노션 완료 체크 기준.

## 로컬 실행

```bash
npm test                                   # 날짜 판정·암호화 테스트
NOTION_TOKEN=... BOARD_PASSWORD=... npm run sync   # site/data.enc.json 생성
python3 -m http.server -d site 8000        # http://localhost:8000
```
