# 서무마을

노션 "서무 할 일"(할 일 메모 DB)을 대구 중구 3D 지도 위에 보여주는 페이지. 실제 지도 데이터(OpenStreetMap)로 도로·동 경계·신천·명소 위치를 잡았고, 동물 주민과 차들이 돌아다닌다.

- **대형 전광판** (국채보상운동기념공원 광장, 남향): 한 면에 숫자 카드·기한 현황 전체·오늘·날짜 지남·유형별·날짜 미정·해낸 일, 시계, 자막. 긴 제목은 글자를 줄여 끝까지 표시
- **업무유형 부스 7곳**: 전광판 앞 반원. 지붕 위 숫자 = 남은 일 (빨강 날짜 지남 / 주황 오늘 / 파랑 그 외). 누르면 그 유형 업무
- **중구청** (남향): 누르면 전체 남은 업무
- **12개 동 행정복지센터**: OSM 실제 위치(동인동·삼덕동·성내1~3동·남산3·4동·대봉1동). OSM에 없는 남산1·2동·대봉2동·대신동은 동 경계 중심에 두고 '대략 위치'로 표시. 건물은 가장 가까운 길을 바라보게, 도로와 겹치지 않게 배치. 바닥에 동 경계선과 동 이름
- **도로**: 달구벌대로·국채보상로·중앙대로·공평로·동덕로·서성로·달성로·태평로·명덕로·신천대로 실제 선형 + 골목길, 동성로 보행자 거리
- **명소**: 서문시장, 교동시장, 방천시장, 스파크랜드(옥상 관람차 회전), 국채보상운동기념공원(달구벌대종), 2·28기념중앙공원, 경상감영공원(선화당), 달성공원, 계산성당, 청라언덕, 약령시 한방거리, 대구근대역사관, 경북대학교병원, 대구제일교회, CGV 대구한일, 대구백화점, 현대백화점, 김광석다시그리기길, 대구역
- **교통**: 실제 도로 따라 승용차·택시·시내버스·배달 오토바이, 교차로 신호등·횡단보도, 버스정류장 정차. 도시철도 3호선 고가(달성공원~대봉교, 실제 역 위치에 정차), 1·2호선 출입구
- **유동인구**: 광장·동성로·시장·인도·정류장·각 동 앞 주민 100명 안팎 (저사양 모드는 절반)
- 빈 블록은 상가·사무실·아파트로 채움 (큰길가는 높게, 동성로 주변은 알록달록 상가)
- **자동 둘러보기**: 전체 → 전광판 → 동성로 → 광장 → 서문시장 → 중구청 순환 (사무실 TV용)
- 한국시간 기준 낮·노을·밤. 동 이름·중구청 이름표는 멀리서, 명소·역 이름표는 중간 거리에서만 보임
- 단축키: `F` 전체 화면, `B` 전광판 보기, `L` 저장된 비밀번호 지우고 잠그기

주소 옵션: `?demo=1` 예시 데이터, `?lite=1` 그림자 끄기(저사양 PC), `?sky=day|dusk|night` 하늘 고정, `?view=board|plaza|hall|dongseong|seomun|overview` 시점 고정
평면 LED 전광판만 보려면 `board.html`

## 구조

```
노션 ──(GitHub Actions, 평일 10분마다)── scripts/sync.mjs
          │  업무 제목·날짜·상태만 추림 (메모 본문은 안 씀)
          │  BOARD_PASSWORD로 AES-256-GCM 암호화
          ▼
   site/data.enc.json ── GitHub Pages ── 브라우저에서 비밀번호로 복호화
```

레포가 공개라서 코드와 페이지 주소는 누구나 볼 수 있지만, 업무 데이터는 암호화된 파일로만 배포된다. git 기록에도 데이터가 남지 않는다(배포 아티팩트로만 올라감).

## 처음 설정 (한 번만)

1. **노션 통합 만들기**
   [노션 통합 관리](https://www.notion.so/profile/integrations) → 새 통합 → 유형 "내부", 이름 `서무 전광판` → 기능은 **콘텐츠 읽기만** 체크 → 저장 후 **내부 통합 시크릿**(`ntn_...`) 복사

2. **노션 DB에 통합 연결**
   노션 "서무 할 일" 페이지 오른쪽 위 `•••` → 연결(Connections) → `서무 전광판` 추가

3. **GitHub 시크릿 등록**
   레포 Settings → Secrets and variables → Actions → New repository secret
   - `NOTION_TOKEN` : 1번에서 복사한 시크릿
   - `BOARD_PASSWORD` : 전광판 비밀번호 (12자 이상 권장, 암호화 파일은 누구나 받을 수 있어서 짧으면 뚫릴 수 있음)

4. **GitHub Pages 켜기**
   Settings → Pages → Build and deployment → Source: **GitHub Actions**

5. **첫 실행**
   Actions 탭 → "전광판 동기화·배포" → Run workflow
   끝나면 `https://<아이디>.github.io/<레포명>/` 에서 비밀번호 입력 (마을과 평면 전광판 비밀번호 같음)

## 참고

- GitHub 예약 실행은 몇 분씩 늦어질 수 있다. 화면 오른쪽 위에 마지막 동기화 시각이 나오고, 40분 넘게 안 바뀌면 "동기화 지연"으로 표시된다.
- 공개 레포는 60일 동안 커밋이 없으면 GitHub가 예약 실행을 자동으로 멈춘다. 그때는 Actions 탭에서 다시 켜면 된다.
- 비밀번호를 바꾸면 다음 동기화부터 새 비밀번호로 열린다. 기존 화면은 자동으로 잠금 화면으로 바뀐다.
- 날짜가 지난 업무는 "확인" 대상으로만 표시하고 미처리로 단정하지 않는다. 완료 여부는 노션 완료 체크 기준.

## 로컬 실행

```bash
npm test                                   # 날짜 판정·암호화 테스트
NOTION_TOKEN=... BOARD_PASSWORD=... npm run sync   # site/data.enc.json 생성
python3 -m http.server -d site 8000        # http://localhost:8000
```

## 지도 데이터

`scripts/fetch-map.py`로 OpenStreetMap Nominatim에서 받아(`scripts/osm-raw.json`), `scripts/build-map.py`로 마을 좌표(중구청 기준, 1km≈100단위)로 바꿔 `site/map-data.json`에 저장한다. OSM에서 찾지 못한 교동시장·방천시장·김광석길·대구백화점·현대백화점·달성공원 크기 등은 대략적인 위치다.
